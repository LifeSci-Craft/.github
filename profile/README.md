# LifeSci-Craft 的奇妙工具箱

LifeSci-Craft 服务器用得到的插件、数据包与网页，都收在这里。

## MCDR 插件

| 仓库 | 说明 |
| --- | --- |
| [MCDR-ServerLogFilter](https://github.com/LifeSci-Craft/MCDR-ServerLogFilter) | 用可配置的正则规则，把服务端控制台里的刷屏日志从 MCDR 控制台隐去；服务端自身的日志文件不受影响。 |
| [MCDR-ModUpdateChecker](https://github.com/LifeSci-Craft/MCDR-ModUpdateChecker) | 把 `mods` 目录里的每个 jar 与 Modrinth 上已发布的版本逐一比对，告诉管理员哪些 Mod 有新版本。 |

## 数据包

| 仓库 | 说明 |
| --- | --- |
| [CraftHead-26.3](https://github.com/LifeSci-Craft/CraftHead-26.3) | 合成头颅 —— Minecraft Java 26.3 可用版。非官方。 |
| [EndermanFix-26.3](https://github.com/LifeSci-Craft/EndermanFix-26.3) | 末影人修复 —— 26.3 移植版。非官方，与原作者无隶属关系。 |
| [XK-LazyCrafting-26.3](https://github.com/LifeSci-Craft/XK-LazyCrafting-26.3) | 懒人合成 26.3 适配。私有仓库，仅个人使用。 |
